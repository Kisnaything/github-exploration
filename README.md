# Git Exploration

Repository ini dibuat untuk melakukan eksplorasi fitur dasar GitHub.

## Eksperimen

Eksperimen yang dilakukan meliputi:

- Membuat repository
- Membuat dan mengunggah file
- Melakukan commit
- Membuat branch
- Membuat Pull Request
- Melakukan merge
- Menggunakan README sebagai dokumentasi

## Tujuan

Memahami penggunaan dasar GitHub dalam pengelolaan dan pengembangan proyek.
